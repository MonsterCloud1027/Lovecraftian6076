# How to Add Screenshots to README

## Quick Guide

1. **Take screenshots** of your application running
2. **Save them** in this `docs/` folder with these exact names:
   - `chat-interface.png` - Main chat view showing conversation
   - `character-creation.png` - Character creation screen
   - `dice-roll.gif` - Animated GIF of dice rolling (optional but recommended)
   - `scene-transition.png` - Example of scene transition
   - `banner.png` - Project banner/header image (optional)

3. **That's it!** The README.md already references these images, so once you add them, they'll automatically appear.

## Recommended Screenshots

### 1. Chat Interface (`chat-interface.png`)
- Show the main chat window
- Include sidebar with character info and memory
- Show a conversation in progress
- **Size**: 1920x1080 or similar

### 2. Character Creation (`character-creation.png`)
- Show the character creation form
- Include all fields (name, attributes, skills)
- **Size**: 1920x1080 or similar

### 3. Dice Rolling (`dice-roll.gif`)
- Animated GIF showing the 3D dice rolling
- Capture the animation from click to result
- **Tool**: Use ScreenToGif, Kap, or LICEcap
- **Size**: Keep under 5MB, optimize if needed

### 4. Scene Transition (`scene-transition.png`)
- Show a scene transition happening
- Include the Keeper's narration
- **Size**: 1920x1080 or similar

### 5. Banner (`banner.png`) - Optional
- Create a nice header image for the README
- Include project name and tagline
- **Size**: 1200x400 or similar

## Tools for Creating Screenshots/GIFs

### Windows
- **ScreenToGif**: https://www.screentogif.com/
- **Snipping Tool**: Built-in Windows tool
- **ShareX**: https://getsharex.com/

### macOS
- **Kap**: https://getkap.co/
- **Screenshot**: Cmd+Shift+4 (built-in)
- **GIF Brewery**: For creating GIFs

### Linux
- **Peek**: https://github.com/phw/peek
- **Flameshot**: https://github.com/flameshot-org/flameshot
- **SimpleScreenRecorder**: For recording

## Image Optimization

Before committing:
- **PNG**: Use tools like TinyPNG or ImageOptim
- **GIF**: Use EZGIF or similar to optimize file size
- **Keep sizes reasonable**: Aim for < 2MB per image, < 5MB for GIFs

## Testing

After adding images:
1. Open README.md in your markdown viewer
2. Verify all images display correctly
3. Check that paths are correct (should be `./docs/filename.png`)
4. Test on GitHub to ensure images render properly
