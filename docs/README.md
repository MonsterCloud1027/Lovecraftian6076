# Documentation Assets

This folder contains screenshots, GIFs, and other visual assets for the project documentation.

## Adding Screenshots

1. **Take screenshots** of your application:
   - Main chat interface
   - Character creation screen
   - Dice rolling interface
   - Memory/sidebar view
   - Any other key features

2. **Save images** in this `docs/` folder with descriptive names:
   - `chat-interface.png` - Main chat view
   - `character-creation.png` - Character creation screen
   - `dice-roll.gif` - Animated dice rolling (if you have GIF)
   - `memory-sidebar.png` - Memory system view
   - `scene-transition.png` - Scene transition example

3. **Update README.md** to reference these images using:
   ```markdown
   ![Alt text](./docs/image-name.png)
   ```

## Creating GIFs

You can create GIFs using tools like:
- **ScreenToGif** (Windows): https://www.screentogif.com/
- **Kap** (macOS): https://getkap.co/
- **Peek** (Linux): https://github.com/phw/peek
- **LICEcap** (Cross-platform): https://www.cockos.com/licecap/

Recommended GIFs:
- Quick demo of starting a game
- Dice rolling animation
- Scene transition
- Character creation flow

## Image Guidelines

- **Screenshots**: Use PNG format, 1920x1080 or similar resolution
- **GIFs**: Keep file size reasonable (< 5MB), use optimized GIF tools
- **Naming**: Use kebab-case (lowercase with hyphens)
- **Alt text**: Always provide descriptive alt text for accessibility
